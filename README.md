# Beetroot Academy — Embedded Development (ESP32-S3)

PlatformIO-проєкт для ESP32-S3 DevKitC-1 (Arduino framework).
У `src/` + `include/` — поточне завдання, попередні — в `homework/`.

## Поточне: міні-проєкт Automotive

| Кнопка | Коротке натискання | Довге (2000 мс) | Подвійний клік |
|---|---|---|---|
| Замок (реле) | відкрити / закрити | валет-режим: замок відкривається, аварійне блокування знімається (повторне довге — вихід) | — |
| Аварійка | увімк / вимк | — | — |
| Поворотник | лівий увімк / вимк | — | правий увімк / вимк |
| Датчик удару | пригальмовування: червоний LED на 1 с | аварія: двері відкриваються, вмикається аварійка; знімається лише валет-режимом | — |

Поворотники й аварійка блимають з періодом **500 мс**.

### Вимоги і як виконано
1. **Без блокуючого коду** — жодного `delay()`/`while`-очікування. Усі часові інтервали — таймери `esp_timer`.
2. **Без polling** — кнопки працюють на перериваннях (`attachInterruptArg`, `CHANGE`). `loop()` спить на черзі подій FreeRTOS
   і прокидається лише тоді, коли переривання або таймер поклали подію (аналог `__WFI()` з уроку).
3. **Антидребезг для всіх кнопок** — кожен фронт перезапускає таймер на 30 мс; рівень приймається, лише коли фронтів не було 30 мс.
4. **Блимання 500 мс**, 5. **довге натискання 2000 мс** — у [include/config.h](include/config.h).
6. **Кожен компонент окремо, зі своєю машиною станів, шари DL → CL → BL:**

| Шар | Компонент | Стани |
|---|---|---|
| DL (драйвери) | `Button` — переривання + антидребезг | Released / Pressed |
| DL | `Output` — LED або реле | on / off |
| CL (контроль) | `ClickDetector` — короткий / довгий / подвійний клік | Idle / Pressed / LongHeld / WaitSecond / SecondPressed |
| CL | `Blinker` — поворотники та аварійка | Off / Left / Right / Hazard |
| CL | `Lock` — замок на реле | Locked / Unlocked |
| CL | `BrakeLight` — стоп-сигнал | Off / On |
| BL (бізнес-логіка) | `Car` | Normal / Valet / Crash |

Події йдуть знизу нагору: `Button` (DL) → `ClickDetector` (CL) → `Car` (BL), а `Car` керує `Lock`, `Blinker`, `BrakeLight`.

### Схема
| Елемент | Підключення |
|---|---|
| Кнопка «замок» | GPIO7 ↔ кнопка ↔ GND |
| Кнопка «аварійка» | вбудована кнопка BOOT на платі (GPIO0), нічого підключати не треба |
| Кнопка «поворотник» | GPIO16 ↔ кнопка ↔ GND |
| Датчик удару | GPIO18 → провід-контакт; торкання проводом GND = спрацювання (сильний брязкіт — перевірка антидребезгу) |
| Лівий поворотник | GPIO4 → 220 Ом → жовтий LED → GND |
| Правий поворотник | GPIO5 → 220 Ом → жовтий LED → GND |
| Стоп-сигнал | GPIO6 → 220 Ом → червоний LED → GND |
| Замок (реле) | GPIO17 → 220 Ом → база 2N2222 (10 кОм база → GND); колектор → IN реле; емітер → GND; реле VCC/GND — від плати живлення 5 В |

Кнопки — з внутрішньою підтяжкою `INPUT_PULLUP`, зовнішні резистори не потрібні. GND плати живлення з'єднаний з GND ESP.

## Попередні завдання (`homework/`)
- `debounce_idf/` — ДЗ 2.6: debounce на ESP-IDF, state-based на апаратному таймері `gptimer`;
- `timers/` — ДЗ 2.5: апаратний таймер керує витяжним вентилятором (реле), watchdog, лог, LED;
- `debounce/` — ДЗ 2.4: 4 методи debounce + RC-фільтр, порівняльна таблиця;
- `superloop/` — ДЗ 2.3: три незалежні LED (200 / 500 / 1000 мс) у superloop на `millis()`;
- `relay/` — вимірювання часу спрацювання реле (`micros()` + переривання), результати 10 вимірювань;
- `motor_control/` — код з уроку: PWM-керування DC-мотором через транзистор, команди off / low / mid / high з Serial;
- `embedded_blink/` — Blink в стилі Embedded C++: `enum class`, `static constexpr`, кнопка через переривання, час `loop()`;
- `headlight_hazard/` — Варіант 2: адаптивна фара (LDR) + аварійна сигналізація, схема та симуляція Wokwi;
- `1.5_bounce.cpp` — дослідження брязкоту кнопки через переривання;
- `1.6_ldr_alt.cpp` — LDR, АЦП і похибка `analogRead()` vs `analogReadMilliVolts()`;
- `police_flasher.cpp` — поліцейська мигалка.
