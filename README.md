# Beetroot Academy — Embedded Development (ESP32-S3)

PlatformIO-проєкт для ESP32-S3 DevKitC-1.
У `src/` — поточне завдання, попередні — в `homework/`.

## Поточне ДЗ 2.6: Усунення брязкоту контактів на ESP-IDF

Завдання уроку 2.4, переписане на **ESP-IDF** (`framework = espidf`, [src/main.c](src/main.c)).
Метод перемикається командою в Serial Monitor:

| Команда | Метод | Як працює (ESP-IDF) |
|---|---|---|
| `1` | Без debounce | `gpio_isr_handler_add`, interrupt на спадаючий фронт; кожен interrupt збільшує лічильник |
| `2` | Time-based | ISR лише ставить прапорець; у головному циклі подія ігнорується, якщо з попередньої реакції < 50 мс (`esp_timer_get_time`) |
| `3` | State-based на апаратному таймері | як на уроці: перший фронт запускає `gptimer` на 50 мс; в його перериванні перевіряємо, чи кнопка досі натиснута. Брязкіт за ці 50 мс таймер не перезапускає |
| `4` | Polling | interrupt вимкнений; програмний таймер `esp_timer` кожні 5 мс опитує кнопку, машина станів `RELEASED → MAYBE_PRESSED → PRESSED → MAYBE_RELEASED`, рівень має бути стабільним 20 мс |
| `r` | — | обнулити лічильники |

На кожну реакцію перемикається LED і в лог пишеться номер реакції, кількість interrupt і затримка від першого фронту.

### Схема (як у ДЗ 2.4)
| Елемент | Підключення |
|---|---|
| Кнопка | GPIO7 → кнопка → GND |
| Підтяжка | 10 кОм від GPIO7 до 3V3 |
| LED | GPIO4 → 220 Ом → LED → GND |
| RC-фільтр (опційно) | вузол кнопки → 100 Ом → GPIO7; 100 нФ від GPIO7 до GND |

### Результати
Вимірювання для тієї ж схеми і тих самих методів (на Arduino) — у [homework/debounce](homework/debounce/README.md).
Відмінність ESP-IDF-версії: у методі 3 рішення приймає переривання апаратного таймера `gptimer` через 50 мс,
а метод 4 повністю працює в програмному таймері `esp_timer` — головний цикл лише друкує лог.
## Попередні завдання (`homework/`, Arduino framework)
- `timers/` — ДЗ 2.5: апаратний таймер керує витяжним вентилятором (реле), watchdog, лог, LED;
- `debounce/` — ДЗ 2.4: 4 методи debounce + RC-фільтр, порівняльна таблиця;
- `superloop/` — ДЗ 2.3: три незалежні LED (200 / 500 / 1000 мс) у superloop на `millis()`;
- `relay/` — вимірювання часу спрацювання реле (`micros()` + переривання), результати 10 вимірювань;
- `motor_control/` — код з уроку: PWM-керування DC-мотором через транзистор, команди off / low / mid / high з Serial;
- `embedded_blink/` — Blink в стилі Embedded C++: `enum class`, `static constexpr`, кнопка через переривання, час `loop()`;
- `headlight_hazard/` — Варіант 2: адаптивна фара (LDR) + аварійна сигналізація, схема та симуляція Wokwi;
- `1.5_bounce.cpp` — дослідження брязкоту кнопки через переривання;
- `1.6_ldr_alt.cpp` — LDR, АЦП і похибка `analogRead()` vs `analogReadMilliVolts()`;
- `police_flasher.cpp` — поліцейська мигалка.
